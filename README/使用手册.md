# SentinelAI HTML 使用与维护手册

适用版本：1.0.0-html

## 架构说明

该版本是传统服务端 HTML 应用：浏览器通过普通 HTTP 请求获得完整 HTML，表单通过标准 HTTP POST 提交。普通用户和管理员使用隔离的登录入口，普通用户为 `/login`，管理员为 `/admin_login`，登录字段均为 `username` 和 `password`，文件上传使用 `multipart/form-data`。Burp Suite 等代理可以直接识别请求路径、表单字段和响应状态；应用不使用 Streamlit 的 `_stcore/stream` WebSocket 或 Protobuf 控件消息。

核心分析仍使用本机 Ollama `qwen3:0.6b`，继续保留文件白名单、100 MiB 上限、二进制拒绝、编码识别、分段分析、三态结论、动态置信度、原文依据、JSON/Markdown 报告、上传保存和管理员下载/删除。分析会明确识别用户名、姓名、部门身份、电话号码、职位、身份证、住址等个人相关信息，并继续识别账号凭据、系统信息、业务数据和内部资料等类别。无表头 TSV 或空白分隔的人员记录，只要组合出现多项身份字段，也会作为敏感人员身份记录识别。

## 用户操作

1. 普通用户打开 `http://服务器IP:8502/login`；管理员打开 `http://服务器IP:8502/admin_login`。两个入口只接受各自角色的账户。
2. 选择允许的文本文件并点击“上传文件”。合法文件会保存到当前应用目录的 `uploads/`。
3. 查看文件名、大小、编码、行数、SHA-256、预览和预计分段数。
4. 点击“开始 AI 分析”。页面会锁定提交按钮并显示工作进度动画；CPU 推理可能需要数分钟，请等待当前 HTTP 请求返回。
5. 查看“未发现敏感信息”“疑似包含敏感信息”或“发现敏感信息”、模型自评置信度、原文文件依据和发现项。系统根据发现项行号直接从上传文件取回原行，因此即使模型自行输出星号，最终依据也不进行脱敏；页面和导出报告必须按敏感数据严格控制访问。
6. 下载 JSON 或 Markdown 报告。每次成功下载都会写入“文件操作 / 下载分析报告”审计，记录报告编号、下载格式、账户和角色。
7. 点击顶部“上传记录”进入 `/history`，查看当前账户上传过的文件、待分析/已分析状态、最近分析时间和最近报告下载入口。点击“查看并分析”或“查看/重新分析”可重新打开对应上传文件。

## 管理员操作

管理员手动访问 `http://服务器IP:8502/admin_login` 登录，成功后进入 `/admin`。普通用户登录页不展示管理员入口链接。管理员账户不能从 `/login` 登录，普通用户也不能从 `/admin_login` 登录；跨角色提交不建立会话，但对客户端统一返回 HTTP 401 和“账号或密码错误”，不披露角色或正确入口。预置管理员为 `admin` / `admin@123` 和 `supuser` / `Supuser@@@123`；普通用户为 `user1` / `user1@123`。管理员拥有全部功能，普通用户只能上传文件并分析自己的文件。管理员可通过顶部导航和左侧导航使用：

- 文件管理：查看所有用户上传文件的中国时间（UTC+8）、上传用户、文件名、大小、SHA-256、分析状态和报告入口，并下载、分析或删除文件。顶部“上传记录”也会以管理员全量视图展示所有用户记录。
- 账户管理：新建管理员或普通用户、删除、停用、启用账户或修改密码。`admin` 账户不能删除，但可由其他管理员停用并重新启用；当前登录账户不能删除或停用，系统至少保留一个启用账户。
- IP 封禁：支持 IPv4/IPv6 地址，按分钟、小时或天配置 1 分钟至 365 天的封禁时长并填写原因；显示封禁中、已过期和已解除记录。封禁中的记录可手动解除；历史记录可点击“再次封禁”，在弹窗中重新填写时长和原因。
- 系统日志：查看账户登录/注销、账户变更、上传文件及 JSON/Markdown 分析报告的下载/删除记录以及 HTTP 网络流量；报告审计包含报告编号、格式、下载账户和角色。失败登录及 404/405 异常路径会分别标记为疑似爆破或目录扫描样本。支持单条删除、删除全部日志，以及按当前类别导出全部匹配记录为 CSV，删除和导出行为本身也会写入新的审计记录。

IP 封禁在请求进入业务路由前生效，命中后返回 HTTP 403“访问已被禁止”，并写入“IP 封禁”类别日志。系统展示当前请求来源 IP 并禁止封禁该地址，避免管理员误操作后失去后台访问。封禁依据服务端直连客户端地址，不信任 `X-Forwarded-For` 等可伪造转发头；如果部署在反向代理后，需要由代理直接阻断来源地址，否则应用只能看到代理地址。

日志页面支持类别筛选和翻页，默认每页 100 条，可设置为每页 10～500 条，并显示日志总数；数据库继续以 UTC 保存时间，页面及 CSV 导出统一转换为中国时间（UTC+8）显示。执行“删除全部日志”后，本次清空操作及其 HTTP 请求仍会作为新日志保留。

密码以 PBKDF2-SHA256 随机盐哈希保存在 SQLite，不保存明文。默认密码只适合当前演练要求，投入真实环境前必须更换。

两个登录页都只显示品牌、账号、密码和登录按钮。账户停用、账户不存在、密码错误或账户角色与入口不匹配时，对客户端统一提示“账号或密码错误”并返回 HTTP 401，避免暴露账户状态和角色；服务端审计日志仍记录具体拒绝原因。不存在的账户和停用账户也会执行一次 PBKDF2 占位校验，以降低响应时间差异。

## HTTP 接口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET/POST | `/login` | 普通用户身份认证 |
| GET/POST | `/admin_login` | 管理员身份认证 |
| POST | `/logout` | 退出登录 |
| GET | `/`、`/index` | 用户分析页面（需登录） |
| GET | `/history` | 上传记录（普通用户仅本人，管理员为全部用户） |
| POST | `/upload` | 标准 multipart 文件上传 |
| POST | `/analyze/{record_id}` | 启动已上传文件分析 |
| GET | `/reports/{task_id}.json` | 下载 JSON 报告 |
| GET | `/reports/{task_id}.md` | 下载 Markdown 报告 |
| GET | `/admin` | 认证后的文件管理页 |
| GET | `/admin/download/{id}` | 管理员下载上传文件 |
| POST | `/admin/delete/{id}` | 管理员删除文件 |
| GET | `/admin/accounts` | 账户管理页 |
| POST | `/admin/accounts/create` | 新建后台账户 |
| POST | `/admin/accounts/{id}/status` | 启用或停用账户 |
| POST | `/admin/accounts/{id}/password` | 修改账户密码 |
| POST | `/admin/accounts/{id}/delete` | 删除账户 |
| GET | `/admin/ip-bans` | IP 封禁管理页 |
| POST | `/admin/ip-bans/create` | 新增或更新 IP 封禁 |
| POST | `/admin/ip-bans/{id}/unban` | 手动解除 IP 封禁 |
| GET | `/admin/logs` | 审计及网络流量日志 |
| GET | `/admin/logs/export` | 导出全部或指定类别的日志 CSV |
| POST | `/admin/logs/{id}/delete` | 删除单条日志并记录该操作 |
| POST | `/admin/logs/delete-all` | 删除全部日志并记录该操作 |

`/admin`、`/admin/accounts`、`/admin/ip-bans` 和 `/admin/logs` 仅管理员可访问。普通用户访问时返回 HTTP 403；未登录用户访问后台页面时跳转到 `/admin_login`。未登录访问 `/`、`/index`、`/history` 时跳转到 `/login`。`/history` 对所有登录账户开放，但普通用户的查询在存储层强制按 `owner_id` 过滤，只能看到自己的上传记录；管理员查询不做用户过滤。管理员退出后返回 `/admin_login`，普通用户退出后返回 `/login`。

所有改变状态的表单都带签名会话关联的 CSRF Token。登录成功后使用 HttpOnly、SameSite=Lax 的签名浏览器会话 Cookie，不设置 `Max-Age` 或持久 `Expires`，因此关闭全部浏览器窗口后浏览器会清除凭证。默认登录会话在连续 30 分钟无操作后失效，单次登录最长持续 8 小时；每次认证请求都会校验服务端时间戳，过期凭证即使仍被浏览器保留也不能继续使用。

可通过环境变量 `AUTH_SESSION_IDLE_SECONDS` 调整空闲超时（默认 `1800` 秒，允许 60 秒至 24 小时），通过 `AUTH_SESSION_MAX_SECONDS` 调整单次登录最长时长（默认 `28800` 秒，允许 5 分钟至 7 天），且空闲超时不得大于最长时长。浏览器把会话 Cookie 视为整个浏览器进程共享；仅关闭一个标签页或窗口并不会可靠地让其他已打开窗口失效，需要立即停止全部会话时请点击“退出”。部分浏览器恢复上次会话时也可能恢复会话 Cookie，此时仍受上述服务端空闲与最长时长限制。当前默认运行在 HTTP；真实网络应在前方配置 HTTPS 反向代理，并将 SessionMiddleware 的 `https_only` 改为 true。

## 安装与启动

开发运行：

```bash
cd /home/zgy/Desktop/Agent_Work_Path/SentinelAI_html
python3 -m venv .venv
.venv/bin/pip install -r requirements.lock.txt
APP_SECRET_KEY="请替换为至少32字符的随机值" .venv/bin/uvicorn web_app:app --host 0.0.0.0 --port 8502
```

正式安装：

```bash
cd /home/zgy/Desktop/Agent_Work_Path/SentinelAI_html
./deploy/install.sh
```

安装脚本创建独立虚拟环境，生成 `/etc/sentinelai-html.env` 会话密钥，并启用 `sentinelai-html.service`。HTML 版使用 8502，原 Streamlit 版继续使用 8501，两者可以并行运行。

常用维护命令：

```bash
systemctl status sentinelai-html.service
sudo systemctl restart sentinelai-html.service
journalctl -u sentinelai-html.service -n 100 --no-pager
curl --noproxy '*' http://127.0.0.1:8502/
```

## 数据目录

| 路径 | 内容 |
|---|---|
| `uploads/` | 用户上传原文件，内部采用 UUID 随机文件名 |
| `data/sentinelai.db` | 后台账户、上传文件元数据、上传与报告关联、IP 封禁及审计日志 |
| `data/reports/` | 分析生成的 JSON 和 Markdown 报告 |
| `templates/` | Jinja2 HTML 页面 |
| `static/style.css` | 响应式明暗主题样式 |

删除 `uploads/` 或数据库会造成文件与记录不一致。应通过管理员后台删除文件。备份时应同时备份 `uploads/` 和 `data/`，其中可能包含敏感内容，必须限制访问。
