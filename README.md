# SentinelAI HTML

SentinelAI 的传统 HTTP/HTML 架构版本。它使用 Starlette、Jinja2 和 Uvicorn 进行服务端页面渲染，不依赖 Streamlit，也不使用 Streamlit WebSocket/Protobuf 控件协议。

## 用户与权限

- 普通用户登录页：`http://服务器IP:8502/login`，只允许普通用户账户登录。
- 管理员登录页：`http://服务器IP:8502/admin_login`，只允许管理员账户登录；该入口不在普通用户登录页中展示，需要手动访问。
- 管理员：可使用文件上传与分析、文件管理、账户管理、IP 封禁和系统日志。
- 普通用户：只能上传文件、查看自己的文件信息并执行 AI 分析，不能访问后台管理功能。
- 预置管理员：`admin` / `admin@123`、`supuser` / `Supuser@@@123`
- 预置普通用户：`user1` / `user1@123`
- `admin` 账户不能删除，但可由其他管理员停用；当前登录账户不能停用自身，系统始终至少保留一个启用账户。

普通用户和管理员使用彼此隔离的登录入口，两个页面都只展示品牌、账号、密码和登录按钮。跨入口登录、账户停用、账户不存在或密码错误统一返回 HTTP 401 和“账号或密码错误”，页面不会暴露角色、账户状态或正确入口。登录成功后，管理员进入 `/admin`，普通用户进入 `/`。

普通用户的上传记录和报告带有所有者信息，只能访问自己的内容；旧版未记录所有者的文件默认仅管理员可访问。

## 主要入口

- 普通用户登录页：`/login`
- 管理员登录页：`/admin_login`
- 分析工作台：`/` 或 `/index`
- 上传记录：`/history`（普通用户仅本人，管理员为全部用户）
- 管理后台：`/admin`
- 账户管理：`/admin/accounts`
- IP 封禁：`/admin/ip-bans`（历史记录可弹窗再次封禁）
- 系统日志：`/admin/logs`（支持按当前类别导出 CSV）
- 上传目录：当前应用目录的 `uploads/`
- SQLite：当前应用目录的 `data/sentinelai.db`
- 报告目录：当前应用目录的 `data/reports/`

默认账户密码仅用于初始化和演练，部署到真实环境前必须修改，并建议在 HTTPS 反向代理后使用。

管理员可按分钟、小时或天配置 IP 封禁时长，填写封禁原因，查看封禁记录并在到期前手动解除。系统不允许封禁当前管理员请求的来源 IP；封禁按直连客户端地址生效，不信任可伪造的转发头。
